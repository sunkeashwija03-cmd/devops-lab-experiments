# Experiment 10: Install and Explore Selenium

1. Install a current JDK and an IDE (Eclipse, IntelliJ IDEA, or VS Code).
2. Create a Java project and add Selenium WebDriver dependencies (Maven is recommended).
3. Install Chrome and use Selenium Manager with a current Selenium version to manage the browser driver automatically.
4. Run a small test that opens a web page, prints its title, and closes the browser.

Example Java code is in `Main.java`. With Selenium dependencies configured, run the `main` method.
