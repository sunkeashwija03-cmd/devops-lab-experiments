# Experiment 2: Explore Git and GitHub Commands

```bash
git --version
git init
git status
git add .
git commit -m "Initial commit"
git log --oneline
git branch
git switch -c feature-branch
git switch main
git merge feature-branch
git clone REPOSITORY_URL
git remote -v
git push -u origin main
git pull
```

Create the GitHub repository in the browser first. Replace `REPOSITORY_URL` with your repository URL.
