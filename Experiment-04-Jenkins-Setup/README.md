# Experiment 4: Jenkins Installation and Setup

1. Install a supported Java Development Kit (JDK).
2. Install Jenkins using the official instructions for your operating system.
3. Start the Jenkins service.
4. Open `http://localhost:8080`.
5. Follow the setup wizard, install suggested plugins, and create an administrator account.
6. Explore Dashboard, Manage Jenkins, build history, and system information.

Official documentation: https://www.jenkins.io/doc/
Do not commit the Jenkins initial admin password or other credentials.
