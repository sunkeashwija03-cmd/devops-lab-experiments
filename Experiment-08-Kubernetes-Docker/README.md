# Experiment 8: Integrate Docker and Kubernetes

1. Build an application image with Docker.
2. Push the image to a registry such as Docker Hub.
3. Start a Kubernetes cluster (for example, Minikube or Docker Desktop Kubernetes).
4. Create a Deployment and Service using the YAML files in Experiment 9.
5. Check resources with `kubectl get deployments,pods,services`.

Docker builds/packages the image; Kubernetes manages deployment, replicas, networking, and updates.
